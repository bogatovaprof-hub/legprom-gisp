# Реестр Минпромторга для легпрома

Лендинг документального сопровождения Ксении Богатовой: от анализа номенклатуры и требований закупок до формирования реестровых записей.

Сайт на HTML, CSS и vanilla JavaScript. Без сборки, внешних библиотек, CDN, аналитики и формы сбора персональных данных. Шрифты размещены локально. По указанию владельца контакты заменены нейтральными заглушками: ссылки, адрес электронной почты и телефон не опубликованы.

## Файлы

- `index.html` — содержание, контакты, тарифы и SEO.
- `assets/site.css` — оформление и адаптивные правила.
- `assets/calculator.js` — формула, валидация, текст расчёта.
- `assets/site.js` — взаимодействие с калькулятором и копирование.
- `assets/fonts/` — локальные шрифты Inter и лицензия.
- `scripts/calculator.test.cjs` — проверка финансовых сценариев.

## Формула

`100 000 + (маршрутов − 1) × 35 000 + (позиций − маршрутов) × 7 000 + заявок по сырью × 30 000`.

Опция «Работа по договорам подряда» добавляет к расчёту 25 000 ₽ один раз за проект. По умолчанию выключена. Доплата включается в общую сумму и распределяется в остатке платежей по действующим условиям. В программном интерфейсе `contractWork` — необязательное логическое значение; отсутствие равно `false`.

Допустимы один или два маршрута. В каждом маршруте минимум одна позиция. Первая заявка включает одну позицию; вторая заявка также включает одну позицию. Сумма анализа 80 000 ₽ уже включена в полную стоимость и не добавляется сверху. Остаток делится на два равных платежа. При двух маршрутах каждый платёж остатка делится поровну между заявками.

Интерфейс принимает целые значения: позиции 1–1 000, отдельные заявки по производителям сырья 0–1 000. Это технический диапазон калькулятора. Некорректные значения и невозможные сочетания не рассчитываются. Расчёт предварительный; внешние расходы не включены.

Контрольный пример: 6 позиций, 2 маршрута, 0 отдельных заявок по сырью = 163 000 ₽. Платежи: 80 000 + 41 500 + 41 500 ₽. Для каждой из двух заявок доля каждого платежа остатка — 20 750 ₽.

Тот же пример с работой по договорам подряда: 188 000 ₽. Платежи: 80 000 + 54 000 + 54 000 ₽; доля каждого платежа остатка на заявку — 27 000 ₽. Опция и доплата утверждены отдельным указанием владельца 03.09.2026.

## Локальный просмотр и проверки

Откройте `index.html` или запустите любой статический HTTP-сервер в корне проекта. При открытии через `file://` копирование может использовать выделяемое текстовое поле. При отключённом JavaScript доступны содержание, заглушки контактов, тарифы и формула с примером.

```sh
node --check assets/calculator.js
node --check assets/site.js
node --test scripts/calculator.test.cjs
```

GitHub Pages: публикация из корня ветки `main`; `.nojekyll` отключает обработку Jekyll. Сайт использует относительные пути и поддерживает размещение по адресу репозитория.

Публичная история начинается с версии с заглушками. Предыдущие локальные версии с контактными данными в неё не включаются. Для дальнейших публикаций используйте ветку `codex/publication` → `origin/main`; исходную локальную ветку `main` не отправляйте в удалённый репозиторий.

## Редакционные основания

Содержание и тарифы перенесены из предоставленного владельцем коммерческого предложения. Принадлежность к заказчику, индивидуальные предварительные выводы и дата предложения удалены. Исходный документ не входит в репозиторий. Польза сопровождения описана через объём работ и условия; неподтверждённые результаты, сроки, отзывы и финансовые эффекты не добавлены.

Сведения о маршрутах: [официальный сервис ГИСП](https://gisp.gov.ru/pp719v2/i/) и [ТПП: подтверждение производства](https://saratov.tpprf.ru/ru/business/719.php). Маршрут по конкретной позиции определяется при анализе по действующим требованиям. Лендинг не заменяет проверку применимых нормативных актов.
